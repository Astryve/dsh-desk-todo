# dsh-desk-todo · 桌面待办挂件

把「**本周待办 + 长期任务**」贴在桌面右上角的一块小黑板上：不加标题栏、不占任务栏、点空白不挡别的窗口；到点弹窗提醒 + 叮一声。

![本周视图](docs/screenshot-week.png)

- 左边：今天起 7 天的待办（没安排的周末也留一行，避免看不见周末）
- 右边：长期任务和 DDL 倒计时
- 单击任意一条 → 看备注 / 标记完成 / 编辑 / 删除
- 标题栏 **＋** → 新增（**右键 ＋** = 新增长期任务）

## 安装

### 方式一：DSH 插件管理器（推荐）

```bash
dsh plugin --profile desktop add dsh-desk-todo
```

装完重启 DSH（桌面版关掉再开），挂件会自动出现在屏幕右上角。

### 方式二：从 GitHub 装

```bash
dsh plugin --profile desktop add github:你的账号/dsh-desk-todo
```

### 方式三：本地目录（开发用）

```bash
git clone https://github.com/你的账号/dsh-desk-todo
dsh plugin --profile desktop add link:/绝对路径/dsh-desk-todo
```

> 装完**必须重启一次 DSH**：挂件窗口是在宿主进程启动时创建的。

## 第一次打开会看到什么

- 一个空挂件（只有今天到周日的空行 + 空的长期任务区）
- 托盘出现一个小鲸鱼图标，右键有：显示/隐藏、回到右上角、测试提醒、打开数据文件、退出
- 数据文件被创建在：

```
$DSH_HOME/desk-todo/data.json
# Windows 默认： C:\Users\<你>\.dsh\desk-todo\data.json
```

## 怎么加待办

### 1. 手动填

点 **＋**，填标题、日期、开始/结束时间（**时 00–23、分 00–59 全是完整下拉**）、地点、提前几分钟提醒、是否每周重复，最后写备注 → 保存。

### 2. 一句话识别（推荐）

在**备注**里直接粘贴一句人话，点右下角 **「识别」**：

```
15号下午3点在图书馆交作业
```

它会自动拆成：

```
日期 2026-11-15 · 开始 15:00 · 结束 16:00 · 地点 图书馆 · 标题 交作业
```

下面会显示一行青色确认文字，觉得对就点**保存**。

支持的写法：

| 写法 | 例子 |
|---|---|
| 日期 | `15号` `11月20日` `2026-11-20` `今天/明天/后天/大后天` `周五` `下周一` |
| 时间 | `3点` `15点` `7点半` `十点` `9点到11点`，可配 `上午/下午/晚上/中午/凌晨` |
| 地点 | `在图书馆` `地点：主楼W3阶`，也认得 `东区414` `W3阶` `宿舍楼下` `KTV` |
| 标题 | 自动去掉时间和地点，只留动作（`交作业` `开会` `拿快递`） |

识别是**纯本地规则**，不联网、不调模型。

### 3. 直接改 JSON

`data.json` 就是普通 JSON，用编辑器改完存盘，挂件会自己刷新（`repeat: "weekly"` 即每周重复）。

## 提醒怎么响

| 时机 | 表现 |
|---|---|
| 提前 N 分钟（每条可单独设，默认 15） | 右下角弹窗 + 叮一声 |
| 到点 | 弹窗 + 更响的提示音 |
| 逾期未完成 | 每 10 分钟再提醒，最多 3 次 |
| 长期任务临期 | 剩 3 天 / 1 天 / 当天各提醒一次 |

弹窗是自己画的窗口（不吃系统通知权限、不会被「专注助手」吞掉），10 秒后自动消失，点 × 可提前关掉。

## 尺寸与外观

托盘点 **⚙**：

- 4 档预设：`400×220` / `520×330` / `640×400` / `760×460`
- 也可以直接输宽高（300–960 × 140–680）
- 背景不透明度 30%–95%
- 拖动标题栏移动、拖边缘缩放，位置和尺寸都会记住

## 数据格式

```json
{
  "semester": { "name": "2026-2027 秋", "week1Monday": "2026-08-31" },
  "events": [
    {
      "id": "e1",
      "title": "数值分析",
      "day": "2026-11-12",
      "start": "13:30",
      "end": "16:40",
      "place": "武进阶教楼W3阶",
      "color": "gold",
      "remindMin": 15,
      "repeat": "weekly",
      "note": "带上次的作业"
    }
  ],
  "longterm": [
    { "id": "l1", "title": "毕业设计开题", "due": "2026-12-20", "done": false, "note": "" }
  ],
  "settings": { "w": 520, "h": 330, "x": null, "y": 16, "opacity": 0.85 }
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| `day` | `YYYY-MM-DD`；`repeat: "weekly"` 时它决定周几 |
| `start` / `end` | `HH:MM`，24 小时制 |
| `place` | 会被自动简写：`武进东区国际教室414` → `东区414` |
| `color` | 左侧色条：`gold` `green` `blue` `pink` `orange` |
| `remindMin` | 提前几分钟提醒；`0` = 只在到点时提醒 |
| `repeat` | `weekly` / `none` |
| `doneOn` | 某天标记完成的日子（每周重复的待办第二天自动恢复） |
| `longterm.due` | DDL；没有 DDL 可以留空 |

想快速试数据，把仓库里的 `data/example.json` 复制过去即可。

## 配置项（可选）

在 `~/.dsh/profiles/<profile>/cordis.patch.yml` 里覆盖：

```yaml
- id: desk-todo
  config:
    alwaysOnTop: true     # 想让它永远盖在窗口上就打开
    startHidden: true     # 开机先不显示，从托盘点开
    silent: true          # 只弹窗不出声
    right: 24             # 离右边缘的距离
```

## 常见问题

**装完没看到挂件？**
① 重启 DSH 了吗？② 看托盘有没有小鲸鱼图标；③ 挂件默认**沉在最底层**，你开着浏览器/编辑器时它被盖住了，最小化所有窗口就能看到桌面上的它。

**桌面右键刷新后不见了？**
插件会自动重建窗口（0.8 秒内）。如果托盘图标也没了，说明 DSH 退了。

**点桌面图标点不动？**
不会。挂件是个正常窗口，不是置顶覆盖层；不想看到就托盘「隐藏」。

**数据会丢吗？**
不会，全在 `$DSH_HOME/desk-todo/data.json`，随时备份。卸载插件不会删这个文件。

**支持 macOS / Linux 吗？**
窗口逻辑是跨平台的，但弹窗位置、托盘图标只在 Windows 上实测过。

**卸载**

```bash
dsh plugin --profile desktop remove dsh-desk-todo
```

## 隐私

- 全部本地：没有网络请求，不调模型，不上传任何数据
- 识别备注用的是本地正则，不外发
- 唯一的联网可能是 DSH 自己

## 开发

```
lib/index.js      宿主：窗口、托盘、定时提醒（cordis 插件）
lib/preload.cjs   contextBridge，页面只能通过它读写数据
lib/ui/           页面：index.html / style.css / renderer.js / toast.*
assets/           提示音 chime.wav、托盘图标 icon.png
```

页面与宿主之间的 IPC 只有 6 条：`get / save / bounds / opacity / hide / datafile`。
